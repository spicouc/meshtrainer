NOTA D'EXECUCIÓ
---------------
El paquet NO depèn de cap ruta absoluta del build. Per executar el gate des
del directori extret amb un Python preparat externament:

    python3 -m venv /tmp/venv_r6
    /tmp/venv_r6/bin/pip install -r requirements-runtime.txt
    cd <directori_extret>
    export PATH=/tmp/venv_r6/bin:$PATH
    bash RUN_RC5_3_FINAL_GATE.sh

Els runners criden `python3` (resolt via PATH) i `torch`/`numpy` des del
venv preparat; cap ruta absoluta al paquet.
